# 没有成分的食材

## 字段

含量都按每 100 克可食部计。空着表示不知道，不能写成 0。

| 编号 | 字段 | 单位 |
| --- | --- | --- |
|  | 可食部分 | 克，每 100 克食材里能吃的部分，记在食材表 |
| 1 | 能量 | 千卡 |
| 12 | 水分 | 克 |
| 2 | 蛋白质 | 克 |
| 4 | 脂肪 | 克 |
| 5 | 膳食纤维 | 克 |
| 3 | 碳水化物 | 克 |
| 13 | 维生素E | 毫克 |
| 6 | 钠 | 毫克 |
| 7 | 钾 | 毫克 |
| 8 | 磷 | 毫克 |
| 14 | 钙 | 毫克 |
| 9 | 胆固醇 | 毫克 |
| 10 | 饱和脂肪 | 克 |
| 11 | 烹调油 | 克 |

## 计算规则

1. 库里的含量是每 100 克可食部的数，不按购买重量折。
2. 吃进去的量 = 每 100 克含量 × 克数 ÷ 100。结果保留 6 位小数，四舍五入。
3. 没有这一行，就表示这项不知道。不能拿 0 去乘克数。
4. 能量用公布的千卡，不用蛋白质、脂肪、碳水化物再算一遍。
5. 只有名称是烹调油、并且脂肪正好是 100 克的，烹调油才记 100 克。其他食材不记烹调油。
6. 可食部分只说明买来的食材里有多少能吃，当前按克数换算时还没有乘上它。

## 计算示例

草鱼每 100 克蛋白质 16.6 克。吃 150 克：

16.6 × 150 ÷ 100 = 24.900000 克

能量同样算：113 × 150 ÷ 100 = 169.500000 千卡。

没有蛋白质这一行时，不能写成 0 × 150 ÷ 100。

## SQL 示例

草鱼每 100 克：能量 113 千卡，水分 78.1 克，蛋白质 16.6 克，脂肪 5.2 克，钠 46 毫克，胆固醇 86 毫克，维生素E 2.03 毫克，钙 38 毫克。没有的项不插。

`sql
INSERT INTO food_nutrient (food_id, nutrient_code, amount)
SELECT f.id, v.nutrient_code, v.amount
FROM food f
JOIN (
    SELECT 1 AS nutrient_code, 113.0 AS amount
    UNION ALL SELECT 12, 78.1
    UNION ALL SELECT 2, 16.6
    UNION ALL SELECT 4, 5.2
    UNION ALL SELECT 6, 46
    UNION ALL SELECT 9, 86
    UNION ALL SELECT 13, 2.03
    UNION ALL SELECT 14, 38
) v
WHERE f.name = '草鱼' AND f.is_deleted = 0;

-- 吃 150 克：每 100 克含量 × 150 ÷ 100，保留 6 位小数
SELECT t.name,
       ROUND(n.amount * 150 / 100, 6) AS eaten
FROM food_nutrient n
JOIN food f ON f.id = n.food_id
JOIN nutrient t ON t.code = n.nutrient_code
WHERE f.name = '草鱼'
  AND f.is_deleted = 0
  AND n.is_deleted = 0;
`

共 696 种。这些食材在食材表里有名字和分类，成分表里还没有每 100 克含量。
