# 减重餐首批菜谱与食材绑定清单

日期：2026-11-12。状态：规划清单（待配方/烹饪/食品安全/营养审核后发布）。

依据 [V0.x 减重餐竖切范围](2026-11-12-V0.x减重餐竖切范围.md)。本清单只收录库内 **名称唯一且已有成分** 的 `food_id`；`food_id` 以 2026-11-12 测试库快照为准，入库迁移时须再跑一次唯一性校验。

约定：

- 克数为 **建议基准份**（一人份草稿），缩放范围待菜谱审核时锁定。
- 未单独建立 `cooking_transform` 前，生米、生肉按 **生重可食部** 入账，成品营养标为 `ESTIMATED` 或保留原料理论值+缺失说明，不得假装精确熟制结果。
- `StapleRecipes` 中的 USDA 夹具 ID **不**列入本清单正式候选。

1. 生熟折算：大米→熟饭、鸡胸肉熟制出成率（有来源才写）

3. 需要替换 `面条` 低钠或全麦方案时再增条目
