# 真人完整接口测试链路（小程序入口）

状态：**入口改为小程序；本机服务 + 真实测试库**  
日期：2026-11-18  

原则：**微信开发者工具打开小程序 → 点「问餐」→ 模拟真人连点真实 HTTP/SSE → 每轮展示节点分析。**

---

## 1. 跑法

1. 本机启动 `nutritionist-service`（连真实测试 MySQL/Redis/Milvus/模型），端口 `18091`。  
2. 微信开发者工具打开 `miniprogram/`，详情里勾选不校验合法域名。  
3. 首页/导航进入 **问餐** 页（`pages/askmeal/askmeal`）。  
4. 可手动打字，或点「跑完整验收脚本」自动走 R0–R10。

后端 Java E2E IT 仍可作为夜间补充，**首要验收入口是小程序。**

---

## 2. 真实接口（小程序打）

| 接口 | 时机 |
| --- | --- |
| `POST .../preference/warmup` | 进入问餐 / 脚本 R0 |
| `POST .../turns` SSE | 每句对话 |
| `GET .../catalog/matches` | 点名菜系探针 |
| `GET .../memory/facts` | 忌口核对 |
| `POST .../memory/retract` | 治理改口（脚本可选） |
| `GET .../memory/metrics` | 指标可见（可选） |

---

## 3. 节点分析（界面展示）

每轮在「节点分析」面板输出：

`WARMUP` / `SSE_ENVELOPE` / `UNDERSTAND_PLAN` / `RULES_MEMORY` / `RECALL_EXECUTE` / `SESSION` / `ASYNC_SIDE`

失败轮标红并停止自动脚本。
