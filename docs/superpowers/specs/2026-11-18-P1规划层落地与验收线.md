## 怎么做的

1. **阶段**：`SessionMemory.phase`（IDLE / CONFIRMING / RECOMMENDED / ADJUSTING / EMPTY_GUIDE / BLOCKED），Redis 快照同步  
2. **冲突规划**：`DialoguePlanner` 按阶段门禁 + 优先级（MISSING/SUBSTITUTE → REPLACE/ADD → RECOMMEND）；已有菜时增量吞掉同轮 RECOMMEND  
3. **指代**：`SlotResolver`「换一个」默认第一道；序数/焦点优先；模糊多候选才澄清  
4. **空引导**：`EmptyGuideComposer` 按 `RecallEmptyReason` 产出文案 + `ADD_FOODS` / `DROP_CUISINE` / `DROP_TAGS` / `KEEP_WAITING`
