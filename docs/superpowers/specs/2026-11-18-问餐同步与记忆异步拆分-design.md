# 问餐同步链与记忆写路径拆分（企业级）

状态：**已定稿，进入实现**  
继承：长短期记忆 V2.1（MySQL 偏好权威 / Redis 会话）  
目标：问餐关键路径少一次同步 LLM；记忆抽取失败不影响荐菜。

---

## 1. 决定表

| 项 | 决定 |
| --- | --- |
| 问餐同步链 | 偏好投影 → 语义理解（唯一同步文本模型）→ 规划/召回 → 本地拼回复 |
| 记忆 LLM 抽取 | **异步**；失败只打日志/指标，不阻断问餐 |
| 规则忌口（绝对不能吃 / 薄规则） | **同步无模型**提交，本轮硬过滤可用 |
| 历史偏好 | `PreferenceSnapshot`（即会话 `LongTermMemory`）在回合开始只读加载；点问餐/首轮带进理解 prompt |
| 本轮口头约束 | 理解输出 `TurnConstraints`，与 Snapshot 并集过滤 |
| 记忆问答 | 由理解（或同步规则）产出 `memoryQueries`，只读 `PreferenceStore` 作答，不依赖异步写完成 |
| 回复润色 | **不**再调模型统一生成 |

---

## 2. 时序

```text
handle(turn)
  expireDue / bindOwner / requestTaste
  MEMORY_REFRESH     ← 只读权威投影（无 LLM）
  RULES_COMMIT       ← thinFallback 有 events 则同步 commit（无 LLM）
  ASYNC_MEMORY_WRITE ← virtual thread：模型抽取 + commit（失败忽略）
  UNDERSTAND         ← 唯一同步文本模型；入参含 PreferenceSnapshot
  应用 TurnConstraints → turnHints / turnAbsoluteAvoids
  MEMORY_ANSWER      ← 只读（若有 queries）
  PLAN → EXECUTE → SESSION_SAVE
```

---

## 3. 契约

### TurnIntent

```json
{
  "tasks": [ ... 既有白名单 ... ],
  "turnConstraints": {
    "avoidFoods": ["虾"],
    "absoluteAvoidFoods": ["海鲜"],
    "cuisine": "川菜",
    "kind": "",
    "preferTags": ["清淡"],
    "turnHints": ["今天少油"]
  },
  "memoryQueries": [{"type":"PAST_AVOID","subject":""}]
}
```

### 过滤优先级

1. 临床过敏 + Snapshot.absoluteAvoid + **本轮** `turnAbsoluteAvoids` → 硬剔除  
2. Snapshot / 本轮软忌口 → softRank 降权  
3. 召回 filter：Snapshot 菜系/标签/病情 ∪ 本轮 cuisine/kind/tags  

---

## 4. 观测

| Span | 路径 |
| --- | --- |
| `nutrition.turn` / `nutrition.understand` / `nutrition.recall*` | 同步问餐 |
| `nutrition.memory.refresh` | 同步只读投影 |
| `nutrition.memory.extract` / `commit` | 异步写（或同步规则 commit 仍打点） |

---

## 5. 非目标

- MQ / Outbox（仍 V2.1：同步 DB 事务写偏好）  
- 理解模型直接荐菜  
- 异步写成功后本回合强制二次召回  

---

## 6. 验收要点

- 同步问餐路径墙钟不再等待记忆 LLM  
- 「不吃 X + 推荐」本轮靠规则同步或 TurnConstraints 生效  
- 异步抽取失败时荐菜仍成功  
- 理解 prompt 含已加载偏好摘要  

---

## 7. 理解 Prompt 契约（2026-11-18 优化）

- 决策树：GREETING → REPLACE_ONE → ADD_KIND → MISSING/SUBSTITUTE → RECOMMEND → **最后** OUT_OF_SCOPE  
- 少样例覆盖：换一个 / 再加个汤 / 川菜推荐 / 天气域外  
- 入参：PreferenceSnapshot（空=「无」，最多 5 项）+ **当前已荐菜名**  
- 主输出：`tasks` + `turnConstraints`；`memoryQueries` 默认空，口味问答优先规则
