# 高脂血症 B 级食养规格

日期：2026-11-11。状态：规格。高脂血症不升为 A 级。胆固醇和钠的上限由本系统按指南初始化，专业人员可以改写。

依据《慢病与减重食材推荐系统设计》第 13 章，病种逐个建立规格。本文件只写高脂血症。痛风和慢性肾病仍留在后续规格。

## 1. 服务等级

记录病情代码 `HYPERLIPIDEMIA` 或 `HYPERCHOLESTEROLEMIA` 的成年患者保持 B 级。

- 系统不按总能量百分比换算饱和脂肪克数。指南写的是少于总能量的 10%，高胆固醇血症者少于 7%，这依赖当天能量，不做成固定克数。
- 没有有效的专业胆固醇目标时，使用第 2 节的初始上限。
- 专业人员写下的有效 `CHOLESTEROL` 或 `SODIUM` 目标替换对应营养素的初始上限。过期后回到初始上限。

## 2. 初始值

来源：国家卫生健康委《成人高脂血症食养指南（2023年版）》。

正文与高血压指南同一次印发：<https://www.nhc.gov.cn/sps/c100088/202301/f01895a06c5349ef999f25da833c166d/files/1732844468018_41219.pdf>

原文：

- 高脂血症人群胆固醇每日摄入量应少于 300mg。
- 高胆固醇血症者每日胆固醇摄入量应少于 200mg。
- 食盐用量每日不宜超过 5g。钠按《成人高血压食养指南（2023年版）》记为 2000mg。
- 反式脂肪酸每天不宜超过 2g。当前营养素还没有反式脂肪酸代码，这一版不写入求解约束。

初始化规则标识 `nhc-adult-hyperlipidemia-diet`，版本 `2023`：

- `HYPERLIPIDEMIA`：胆固醇上限 300 毫克/天。
- `HYPERCHOLESTEROLEMIA`：胆固醇上限 200 毫克/天。两种代码同时存在时用 200 毫克。
- 钠上限 2000 毫克/天。已有高血压钠约束时，保留更低的那一个上限。
- 指南没有胆固醇下限。配餐硬约束只写上限。

脂肪占总能量 20%～25%、烹调油不超过 25g、饱和脂肪比例，都依赖能量或食物库，不在这一版写成固定克数。
