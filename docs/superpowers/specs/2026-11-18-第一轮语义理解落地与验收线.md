# 第一轮语义理解：怎么做的 & 验到什么线

状态：已验收（2026-11-18）  
范围：问餐同步链里的 **唯一文本模型理解**（不含荐菜召回、不含记忆运营全量）

---

## 1. 怎么做的

### 1.1 流水线

```text
UnderstandContextPacker（会话已荐菜 + phase + 偏好摘要 + 原文/foods）
  → IntentUnderstander 调 1 次文本模型 → TurnIntent JSON
  → IntentNormalizer（枚举/低置信/去重/反抄袭历史）
  → SlotResolver（第 N 个 / 这个 → dishHint；歧义则 ambiguities）
  → IntentSafetyNet（仅当空或假 OUT_OF_SCOPE 时，对高置信句式纠偏）
  → 有 ambiguities → 本回合 CLARIFY，不找菜
  → 否则交给既有 Planner/Executor
```

### 1.2 关键代码

| 模块 | 路径 |
| --- | --- |
| 编排接入 | `DialogueOrchestrator`（pack → interpret → clarify 短路） |
| 理解器 | `IntentUnderstander` |
| 入参包 | `UnderstandContext` / `UnderstandContextPacker` |
| 后处理 | `IntentNormalizer` / `SlotResolver` / `IntentSafetyNet` |
| 契约 | `TurnIntent` / `TurnConstraints` / `IntentAmbiguity` |

### 1.3 设计原则

- 同步只 **1 次**理解 LLM；记忆模型抽取走旁路异步（另文）  
- 模型只出白名单任务 + 本轮约束；不荐菜、不改克数  
- 不确定就澄清，不硬猜  
- 假域外用词法护栏兜底固定句式（换/加汤/没有了/代替），不开放域乱猜

## 2. 验到什么线

### 2.1 门槛（方案约定）

| 指标 | 门槛 |
| --- | --- |
| Task-set Exact | ≥ 92% |
| Critical miss（换菜/加汤/绝对忌口等） | ≤ 2% |
| 假 OUT_OF_SCOPE | ≤ 1% |
| 同步理解调用次数 | = 1 |

### 2.2 实测（2026-11-18）

金标：`src/test/resources/understand-gold/v1/gold-1000.jsonl`（1000 条，分桶模板生成）

| 验证 | 命令要点 | 结果 |
| --- | --- | --- |
| Oracle 流水线 | `UnderstandGoldValidationTest`（注入标准 modelJson） | **1000/1000，taskSet=100%，criticalMiss=0%** |
| Live 抽检 100 | `-Dunderstand.gold.live=true -Dunderstand.gold.limit=100` | 首轮 **53%**（假 OOS）→ 加 SafetyNet 后 **100%** |
| Live 全量 1000 | `-Dunderstand.gold.live=true -Dunderstand.gold.limit=1000` | **1000/1000，taskSet=100%，criticalMiss=0%，falseOos=0** |

### 2.3 结论线

- **本小步（理解）**：达到并超过方案门槛，可进预发/灰度。  
- **不等于**整包问餐产品已上线：金标偏模板句式；开放长尾仍靠模型+护栏；荐菜/召回需另验。  

复跑：

```text
mvn -Dtest=UnderstandGoldValidationTest test
mvn -Dtest=UnderstandGoldLiveValidationIT -Dunderstand.gold.live=true -Dunderstand.gold.limit=1000 test
```

## 3. 与偏好读写的边界

| 路径 | 是否本小步 | 说明 |
| --- | --- | --- |
| 查用户偏好（Snapshot 只读进 ContextPack） | 衔接 | 理解 prompt 带忌口/菜系等摘要 |
| 规则同步落库（绝对不能吃等） | 问餐链同步 | 无 LLM，本轮可硬过滤 |
| 旁路异步模型落库 | **旁路** | `AsyncMemoryWriter`，失败不影响理解/荐菜 |

### 3.1 偏好查询与旁路落库检查（已测）

| 项 | 行为 | 测试 |
| --- | --- | --- |
| 查偏好 | `refreshLongTerm` → Snapshot 进会话；`ContextPack`/`prompt` 带忌口菜系 | `preferenceLookupHydratesLongTermForAskMeal` |
| 规则同步落库 | `extractRulesOnly` → `commit`，问餐不等模型抽取 | `syncRulesCommitAvoidBeforeUnderstand` |
| 旁路异步落库 | `AsyncMemoryWriter.writeQuietly` 规则/模型 enrichment | `bypassAsyncWriteCommits*` |
| 旁路失败 | 抛错只打日志，不污染已有偏好 | `bypassAsyncWriteFailureDoesNotThrowAndDoesNotCorruptStore` |
| Loader | patient/owner 共读 PreferenceStore | `loaderOwnerAndPatientSharePreferenceStore` |
