# 偏好查询与旁路落库：怎么做的 & 验到什么线

状态：已达标（2026-11-18）  
范围：问餐链 **查 Snapshot** + **规则同步写** + **AsyncMemoryWriter 旁路写**（不含理解任务拆分）

## 怎么做的

1. **查**：`LongTermMemoryLoader` / `refreshLongTerm` → 会话 `longTerm`；`UnderstandContextPacker` 带进理解  
2. **同步写**：`extractRulesOnly` → `commit`（无 LLM）  
3. **旁路写**：`AsyncMemoryWriter` 虚拟线程；失败只日志；投影已覆盖则跳过重复写  

## 本步规则抽取硬化

- AVOID 主体非贪婪 + 边界前瞻，避免「我不吃海带帮推荐」吞成「海带帮」  
- LIKE 加 `(?<!不)`，避免「不喜欢」被 LIKE 覆盖成喜好  
- `cleanSubject` 循环剥「帮推荐/帮/推荐」尾缀  
- 新增「对 X 过敏」→ ABSOLUTE AVOID
