# V0.x 减重餐竖切范围

日期：2026-11-12。状态：已确认决策。

本文件收窄下一阶段交付物，不修改 [慢病与减重食材推荐系统设计](2026-11-10-慢病与减重食材推荐系统设计.md) 的 A/B/C 分级原则。冲突时以主规格为准；本文件只约束「先做什么、不做什么」。

## 1. 决策结论

- 病种分期合理：先打通一条可自动配餐竖切，再按病种扩展。
- 第一刀是 **减重餐竖切（A 级最小集）**，不是「纯减肥、完全不做糖尿病」。
- 高血压、高脂血症、痛风、慢性肾病保持 **B 级**：只执行专业目标或已发布初始上限，不在本竖切内自动推导临床目标。
- 不引入向量库、Elasticsearch、Neo4j；食材与菜谱用精确名称 / `food_id` 匹配。
- 医院诊断不进本仓。临床快照边界见 [2026-11-13-公共HIS与临床快照边界.md](2026-11-13-公共HIS与临床快照边界.md)。快照为空视为未申报慢病。

## 2. 首批人群

允许进入本竖切自动目标与配餐的用户须同时满足主规格 §2.1，并按下表验收：

| 项 | 本竖切要求 |
| --- | --- |
| 年龄 | 年满 18 岁 |
| 主目标 | 减重（超重/肥胖或明确减重目标） |
| 可选合并 | 病情稳定的 2 型糖尿病或糖尿病前期 |
| 排除 | 主规格 §2.3 C 级与 §2.1 排除项一律不进自动求解 |
| 高血压等 | 仅当存在有效专业目标或已发布 B 级初始上限时可带约束配餐；系统不新推临床目标 |

产品对内可称「减肥餐」，技术验收仍须覆盖减重热量缺口、蛋白质下限、餐次碳水范围；带 2 型糖尿病/前期时启用控糖相关数据门槛。

## 3. 数据门槛

- 候选食材必须在 MySQL `food` 中唯一，且具备本次约束所需的 `food_nutrient`（至少能量、蛋白质；控糖场景还须碳水）。
- `UNKNOWN` 不得当 0；关键营养素缺失则该食材对本场景 `REJECT`（主规格 §4.6）。
- 只用已授权开放来源或已审核入库数据；不补齐《中国食物成分表》未授权内容。
- 约 696 种尚无成分的食材不阻塞竖切：只服务首批菜谱实际用到的食材，按菜补齐。
- 对话侧 `UsdaFoodCatalog` / `StapleRecipes` 仅作工程夹具；本竖切正式候选以库内中国市场食材与已发布菜谱版本为准。

## 4. 菜谱覆盖矩阵

首批不以「100 道」验收，按主规格 §17.7 矩阵：

| 维度 | 最低要求 |
| --- | --- |
| 餐次 | 能组出早餐、午餐、晚餐；可含 1 种加餐简单食物 |
| 主食 | ≥2 种已发布方案（如米饭类生米折算、燕麦/全麦面包） |
| 蛋白质 | ≥3 种来源（禽肉、蛋、豆制品；可再含水产或畜肉） |
| 蔬菜 | ≥3 种已发布菜或简单蔬菜食物 |
| 简单食物 | ≥2 种（水果、奶类等 `SIMPLE_FOOD`） |
| 烹调油与盐 | 油、盐必须作为配料显式入账，不得藏在自然语言 |
| 厨具 | 覆盖「碗 / 锅」新手可执行；不依赖烤箱等未声明设备 |
| 审核状态 | 仅 `PUBLISHED` 且依赖数据仍有效的版本可进求解 |

详细菜名与 `food_id` 绑定见 [2026-11-12-减重餐首批菜谱食材绑定清单.md](2026-11-12-减重餐首批菜谱食材绑定清单.md)。

## 5. 求解与校验

- 决策变量：`RECIPE_PORTION` + `SIMPLE_FOOD`。
- 硬约束：过敏/禁忌、热量范围、蛋白质下限、餐次碳水范围；若带 B 级有效上限则并入（如钠、胆固醇）。
- Java 按 `food_id` 与克数复算；求解器与模型不得提交可信汇总。
- 无可用已发布菜谱时，不得宣称完整菜品或分步教程。

## 6. 扩展顺序

1. 本竖切：减重 ± 可选稳定 2 型糖尿病/前期，审核菜谱与精确绑定跑通。
2. 强化 B 级可执行验收：高血压钠、高脂血症胆固醇等（已有独立规格）。
3. 单个病种升 A 级：每次补齐准入、排除、数据要求、冲突测试与专业审核。

## 7. 非目标（本竖切明确不做）

- 向量库 / 语义召回作为主匹配或决定克数。
- 一次实现全部病种 A 级自动目标。
- 1028 种待补食材全库补齐。
- 未审核网络菜谱、模型临场发明关键用量或温度。
- 独立知识图谱产品或图数据库。
- 用相似食材数值冒充缺失成分。

## 8. 完成标志

- 给定符合 §2 的画像，无模型也能返回一日或单餐方案。
- 方案中每道 `RECIPE_PORTION` 可追溯到 `recipe_version` 与精确 `food_id` 配料。
- Java 复算通过；关键营养素有来源；覆盖矩阵表各项达标。
- 高血压等未升 A 的病种不会被系统自行推导目标。
