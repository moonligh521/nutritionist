# 对话规划与增量推荐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 将 agent turns 从「必须 foods 的单次工具环」升级为「会话记忆 + 模型理解 + Java 规划增量执行」。

**Architecture:** `AgentTurnController` → `DialogueOrchestrator`（装载记忆 → Understand → Plan → Execute）→ 现有 `DishRecommendService` / `IngredientAgent` 能力复用为执行步骤。会话存内存实现，可换 Redis。

**Tech Stack:** Java 21、Spring Boot、现有 `ModelCompletion`、JUnit 5
